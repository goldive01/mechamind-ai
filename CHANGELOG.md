# Changelog

All notable changes to MechaMind AI are documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses semantic versioning.

## [1.3.1] - 2026-08-26

### Added

- Professional open-source project README with local screenshot assets.
- Architecture documentation with Mermaid diagrams for system, request, repository, Copilot, alert, and notification workflows.
- Database documentation with entity relationships, constraints, cascades, migrations, and persistence boundaries.
- Complete API and route reference with requests, responses, and status codes.
- Engineering guide covering architectural patterns, services, DTOs, and intelligence engines.
- MIT license and repository screenshot placeholders.

### Changed

- Marked the complete Version 1.3 engineering intelligence release in the roadmap.
- Added the Version 1.4 connected-operations roadmap covering mobile field engineering, work orders, inventory, authentication, multi-organisation support, and cloud deployment.

### Notes

- This documentation release does not change application logic, APIs, database schema, dependencies, tests, or UI behavior.

## [1.3.0]

### Added

- Alert domain, automatic evaluation, lifecycle management, and Alert Center.
- Deterministic and optionally AI-enhanced engineering recommendations.
- Asset timeline intelligence with trends and summaries.
- Notification queue, severity policies, escalation rules, and log-only provider adapters.

## [1.2.0]

### Added

- Context-aware Engineering Copilot, streaming chat, tools, confirmations, and conversation history.

## [1.1.0]

### Added

- Repository, service, domain, DTO, health-engine, logging, and testing foundations.

## [1.0.0]

### Added

- Initial asset, inspection, AI report, health, predictive maintenance, and IoT capabilities.
